# MomStage – ลูกฉันอายุเท่านี้ ต้องทำอะไร

เว็บแอปผู้ช่วยคุณแม่ชาวไทย ตั้งแต่ **ตั้งครรภ์จนลูกอายุ 3 ขวบ**

ผู้ใช้กรอกข้อมูลแค่ **วันเดียว** คือ วันกำหนดคลอด (ถ้ากำลังตั้งครรภ์) หรือ วันเกิดลูก (ถ้าคลอดแล้ว)
จากนั้นแอปจะ **คำนวณเอง** ว่า "ตอนนี้" ลูกอยู่ช่วงไหน เช่น อายุครรภ์กี่สัปดาห์ อายุลูกกี่เดือนกี่วัน
วัคซีนเข็มถัดไปคือวันไหน ควรเช็กพัฒนาการอะไร และต้องเตรียมของอะไร ทุกหน้าในแอปปรับตามช่วงวัยให้อัตโนมัติ

> แอปนี้ไม่ใช่เว็บขายของหรือเว็บคอนเทนต์ ทุกฟีเจอร์มีตรรกะคำนวณจากวันที่ของผู้ใช้ และอธิบายที่มาได้ (ดูหัวข้อ "ตรรกะหลัก")

## ตรรกะหลัก (อยู่ไฟล์ไหน คิดอย่างไร)

### 1. อายุครรภ์ — `src/lib/age.ts` → `getPregnancyWeek(dueDate, today)`

```
อายุครรภ์ = 40 สัปดาห์ − เวลาที่เหลือถึงกำหนดคลอด
          = 280 วัน − (วันกำหนดคลอด − วันนี้)
```

คำนวณเป็น "วัน" ก่อนแล้วค่อยแปลงเป็น สัปดาห์ + วัน เพื่อไม่ให้เศษคลาดเคลื่อน
ตัวอย่าง: กำหนดคลอด 1 มี.ค. 2570, วันนี้ 7 พ.ย. 2569 → เหลือ 114 วัน → 280 − 114 = 166 วัน = **23 สัปดาห์ 5 วัน (ไตรมาส 2)**

ไตรมาส: 1 = 0–13 สัปดาห์, 2 = 14–27 สัปดาห์, 3 = 28 สัปดาห์ขึ้นไป

ถ้าไม่รู้วันกำหนดคลอด คำนวณจากวันแรกของประจำเดือนครั้งสุดท้าย (LMP) ได้ด้วย
`getDueDateFromLMP(lmp)` = LMP + 280 วัน (กฎของ Naegele)

### 2. อายุลูก — `src/lib/age.ts` → `getBabyAge(birthDate, today)`

คืนค่า `{ months, days, totalDays, totalWeeks }`

1. `months` = จำนวนเดือนเต็มจากวันเกิดถึงวันนี้ (`differenceInMonths` ของ date-fns)
2. วันครบเดือนล่าสุด = วันเกิด + `months` เดือน
3. `days` = วันนี้ − วันครบเดือนล่าสุด

เคสพิเศษที่ทดสอบไว้:
- **เกิดวันที่ 31** → ครบเดือนในเดือนที่สั้นกว่าคือวันสุดท้ายของเดือนนั้น เช่น เกิด 31 ม.ค. ครบ 1 เดือนวันที่ 28 ก.พ. (หรือ 29 ก.พ. ในปีอธิกสุรทิน)
- **ปีอธิกสุรทิน** → เกิด 29 ก.พ. 2571 ครบ 1 ขวบวันที่ 28 ก.พ. 2572
- `days` ไม่ติดลบเลย (ทดสอบวนทุกวันตลอด 3 ปี)

### 3. ตรวจความถูกต้องของวันที่ — `src/lib/childStatus.ts` → `validateChildDate()`

- ตั้งครรภ์: อายุครรภ์ที่คำนวณได้ต้องอยู่ระหว่าง 0–42 สัปดาห์
- คลอดแล้ว: วันเกิดต้องไม่อยู่ในอนาคต และอายุไม่เกิน 3 ขวบ

### 4. วัคซีน — `src/lib/vaccine.ts` → `getVaccineSchedule(child, today)`

- วันนัด = วันเกิด + `ageMonths` เดือน (`addMonths`) — ถ้ายังตั้งครรภ์ใช้วันกำหนดคลอดเป็นวันเกิดโดยประมาณ (`isEstimate`)
- สถานะ: **done** มีวันที่ใน vaccineLog → **overdue** เลยวันนัดเกิน 30 วัน → **due** ช่วง 14 วันก่อนถึง 30 วันหลังวันนัด → **upcoming**
- เข็ม "เฉพาะกรณี" (`optional`) เช่น HB2, โรต้าครั้งที่ 3 ไม่ถูกนับเป็นเข็มค้าง
- `buildVaccineSummaryText()` สร้างข้อความสรุปสำหรับส่ง LINE

### 5. นัดฝากครรภ์ — `src/lib/pregnancy.ts` → `getPregnancyMilestones(dueDate, today)`

- อายุครรภ์จาก `getPregnancyWeek()` → สถานะ: เลย `weekTo` = past, อยู่ใน `weekFrom–weekTo` = current, ยังไม่ถึง = upcoming
- ช่วงวันที่จริง: LMP = กำหนดคลอด − 280 วัน, วันเริ่ม = LMP + weekFrom สัปดาห์, วันจบ = LMP + (weekTo+1) สัปดาห์ − 1 วัน

### 6. Checklist — `src/lib/checklist.ts` → `getRelevantStages(child, today)`

- ตั้งครรภ์ใช้ "สัปดาห์" / คลอดแล้วใช้ "เดือน" หาช่วงที่ `from ≤ อายุ < to` แล้วคืนช่วงนี้ + ช่วงถัดไป พร้อม % ที่ติ๊กแล้ว

### 7. ควิซพัฒนาการ — `src/lib/quiz.ts`

- `getQuizForAge(อายุเต็มเดือน)` เลือกช่วงอายุ DSPM ให้อัตโนมัติ (เลือกช่วงอื่นเองได้)
- ตอบ 3 แบบ: ทำได้ / ยังทำไม่ได้ / ไม่แน่ใจ
- `scoreQuiz()` สรุปรายด้าน: ทำได้ครบ = **สมวัย**, มีข้อทำไม่ได้ = **ควรส่งเสริม** (แสดงกิจกรรมฝึก), มีแต่ไม่แน่ใจ = **ลองสังเกตอีกครั้ง**
- ถ้าไม่ผ่านทุกข้อ → `retestDate` = วันที่ทำ + 30 วัน (DSPM: ฝึก 1 เดือนแล้วประเมินซ้ำ)
- ทำซ้ำแล้ว **ข้อเดิม** ยังทำไม่ได้ → `referral` แนะนำปรึกษาเจ้าหน้าที่คลินิกเด็กดี

### 8. กราฟการเจริญเติบโต — `src/lib/growth.ts`

- อายุ (แกน X) = จำนวนวันตั้งแต่เกิด ÷ 30.4375 (`getAgeInMonthsExact` ใน age.ts, นิยามเดียวกับ WHO)
- ค่า L, M, S ที่อายุนั้น interpolate ระหว่างเดือน แล้ว `z = ((X/M)^L − 1) / (L·S)` → เปอร์เซ็นไทล์จากการแจกแจงปกติ
- น้ำหนักที่ |z| > 3 ใช้วิธีปรับค่าสุดขั้วตามรายงาน WHO
- แปลผล: ต่ำกว่า P3 = น้อยกว่าเกณฑ์ ควรปรึกษาแพทย์ / P3–P97 = อยู่ในเกณฑ์ / สูงกว่า P97 = มากกว่าเกณฑ์
- เตือนเมื่อเปอร์เซ็นไทล์ตกลงข้ามเส้นหลัก (P3, P15, P50, P85, P97) ตั้งแต่ 2 เส้นระหว่างการชั่ง 2 ครั้งติดกัน (ค่าคงที่ `CROSSING_ALERT_MIN_LINES`)

### 9. ลูกป่วย ควรไปหาหมอไหม — `src/lib/sick.ts`

- เลือกอาการหลัก (ไข้ / อาเจียน / ท้องเสีย / ผื่น / ไอ) ได้หลายอย่าง → `getNextQuestion()` ถามเฉพาะข้อที่ `showIf` ตรงกับอาการ
- ทุกเส้นทางถามสัญญาณอันตรายก่อน (ชัก ซึม หายใจหอบ ปากเขียว) และหยุดถามทันทีเมื่อเจอกฎสีแดง
- `triage()` ตรวจกฎทั้งหมดใน `sickRules.ts` ใช้ระดับสูงสุดที่ตรง (แดง > เหลือง > เขียว) และแสดงเหตุผลทุกข้อ
- กฎแดงขั้นต่ำ: อายุ < 3 เดือนและไข้ ≥ 38.0 °C, ชัก, ซึมปลุกไม่ตื่น, หายใจหอบ/อกบุ๋ม, ริมฝีปากเขียว, กระหม่อมบุ๋ม, ปัสสาวะ < 3 ครั้ง/24 ชม., ร้องไม่มีน้ำตา, ผื่นจุดเลือดออกกดไม่จาง, ไข้เกิน 3 วัน
- ผลสีแดงมีปุ่มโทร 1669 (`tel:1669`) · ทุกหน้ามีข้อความ “ไม่ใช่การวินิจฉัย”
- แหล่งอ้างอิง (ระบุรายกฎใน `sickRules.ts`): NICE NG143 *Fever in under 5s* (traffic light), NICE CG84 *Diarrhoea and vomiting in under 5s*, WHO *IMCI Chart Booklet* (2014) · “ไข้เกิน 3 วัน = แดง” เป็นข้อกำหนดของโปรเจค (NICE จัดไข้ ≥ 5 วันเป็นเหลือง)

### 10. ลูกคนนี้ใช้เงินเท่าไหร่ — `src/lib/babyCalc.ts`, `src/lib/careLog.ts`

- ปริมาณนม/วัน = 150 มล. × น้ำหนัก (ไม่เกิน 1,000 มล.) ÷ จำนวนมื้อ = มล./มื้อ (ค่าประมาณ สำหรับอายุ < 6 เดือน)
- นมผง: ช้อน/วัน = มล. ÷ 30 → กรัม = ช้อน × 4.3 → กระป๋อง/เดือน = กรัม × 30 วัน ÷ กรัมต่อกระป๋อง
- ผ้าอ้อม/วันตามอายุ: แรกเกิด 10–12, 1–5 เดือน 8–10, 6–12 เดือน 6–8, 1 ปีขึ้นไป 4–6 (คิดค่ากลาง)
- เลือกแบบการให้นม (นมแม่ล้วน / ผสม / นมผงล้วน) — นมแม่ล้วนไม่ต้องกรอกราคานมผงก็ดูกราฟได้
- ค่าใช้จ่ายอื่นต่อเดือนที่เพิ่มเอง (วัคซีน เสื้อผ้า ของใช้): หนึ่งรายการมีได้หลายยอด แต่ละยอด = ราคาต่อหน่วย × จำนวน · รายการชื่อซ้ำรวมเป็นแท่งเดียว (`buildMonthlyExpenses`)
- กราฟแท่งแนวนอนแสดงทุกรายการของแบบที่เลือก + กราฟแท่งซ้อนเปรียบเทียบ 3 แบบ (เมื่อกรอกราคานมผง)
- ค่าที่กรอกทั้งหมดจำไว้ใน store ของลูกแต่ละคน (`calcSettings`)
- แหล่งอ้างอิง: 150 มล./กก./วัน ตามช่วงที่ใช้ทั่วไป 150–200 มล./กก./วัน (เช่น NHS Bottle feeding advice) · 1 ช้อน ≈ 4.3 ก. ต่อน้ำ 30 มล. ตามฉลากนมผงสูตรมาตรฐาน (ควรตรวจกับยี่ห้อที่ใช้จริง) · จำนวนผ้าอ้อมเป็นค่าประมาณตามที่โจทย์กำหนด
- บันทึกนม/นอน: ปุ่มเดียวเริ่ม/หยุด (`toggleCare`) · สรุปวันนี้ตัดช่วงข้ามเที่ยงคืนด้วย date-fns · ทารก < 1 เดือนห่างมื้อล่าสุดเกิน 3 ชม. = เตือนสีเหลือง

### 11. ชุมชนแบ่งตามช่วงวัย — `src/lib/posts.ts`

- `stageTag` คำนวณตอนโพสต์จากอายุลูกของคนโพสต์ ณ วันนั้น: ตั้งครรภ์ไตรมาส 1/2/3 (< 14, 14–27, ≥ 28 สัปดาห์), 0–3, 4–6, 7–12 เดือน, 1–2 ปี, 2–3 ปี
- `sortFeed()` เรียงช่วงเดียวกับผู้ใช้ก่อน → ช่วงถัด ๆ ไปตามลำดับ (เตรียมตัวล่วงหน้า) → ช่วงที่ผ่านมาแล้ว · ในช่วงเดียวกันเรียงใหม่ก่อน
- "มีประโยชน์" นับได้ 1 ครั้งต่อโพสต์ต่อเครื่อง กดอีกครั้งเพื่อยกเลิก · กรองหมวด สุขภาพแม่ / นมแม่ / การนอน / อาหารเสริม / ของใช้ที่รีวิว
- รีวิวของใช้ใส่ชื่อสินค้าและรูปได้ (ย่อรูปเหลือด้านยาว 720 px ก่อนเก็บ) · `containsLink()` ปฏิเสธลิงก์ เว็บไซต์ ไอดีไลน์ และชื่อแพลตฟอร์มขายของในทุกช่อง
- ที่มาของข้อมูล: โพสต์ตัวอย่าง 12 โพสต์ใน `communitySeed.ts` เป็นประสบการณ์สมมติ ไม่มีชื่อแบรนด์และลิงก์ ที่เหลือมาจากผู้ใช้
- `postRepository` เก็บใน localStorage (คีย์ `momstage:posts:v1`) ทุก method คืน Promise — เปลี่ยนเป็น Firestore ได้โดยเขียน repository ใหม่ที่มี method เดียวกันแล้วแก้บรรทัดสุดท้ายของไฟล์

### 12. พิกัดห้องให้นม/เปลี่ยนผ้าอ้อม — `src/lib/places.ts`

- แผนที่ใช้ Leaflet + OpenStreetMap (ฟรี ไม่ต้องใช้ API key) · ปุ่ม “หาใกล้ฉัน” ใช้ `navigator.geolocation` (ต้องเปิดผ่าน https หรือ localhost)
- ระยะทาง = สูตร haversine บนทรงกลมรัศมี 6,371 กม. → รายการเรียงใกล้ก่อน (ไม่รู้ตำแหน่ง ใช้ใจกลางกรุงเทพฯ)
- สถานะ: ยืนยัน “ยังมีอยู่” ภายใน 90 วัน = สีเขียว · ไม่มีคนยืนยันเกิน 90 วัน = สีเทา · รายงาน “ปิดแล้ว” ใหม่กว่าการยืนยัน = สีแดง
- ปุ่ม “ยังมีอยู่ / ปิดแล้ว” 1 เสียงต่อจุดต่อเครื่อง เปลี่ยนใจได้ และกดปุ่มเดิมซ้ำเพื่อยกเลิก (คืนค่า `lastConfirmed` เป็นค่าก่อนกด)
- นำทาง: `https://www.google.com/maps/dir/?api=1&destination=lat,lng`

**ที่มาของข้อมูล**

1. **จุดตั้งต้น (seed) 19 จุด** — `src/data/nursingRoomsSeed.ts`: ห้างใหญ่ 13 แห่ง โรงพยาบาลรัฐ/โรงเรียนแพทย์ 4 แห่ง และสนามบิน 2 แห่งในกรุงเทพฯ พิกัดเป็นระดับอาคารจาก OpenStreetMap (คลาดเคลื่อนได้ 100–200 ม.) ชั้นของห้องให้นมใส่เฉพาะที่มีรีวิวผู้ใช้ระบุ (CentralWorld ชั้น 6, Siam Paragon ชั้น 3, ICONSIAM ชั้น 4, EmQuartier ชั้น 2–3) จุดอื่นเว้นว่างให้ผู้ใช้ช่วยเติม จุดตั้งต้นนับว่า “ยืนยันโดยแอป” ณ วันที่โหลดครั้งแรกจึงแสดงเป็นสีเขียว และจะกลายเป็นสีเทาถ้าไม่มีผู้ใช้กด “ยังมีอยู่” ภายใน 90 วัน
2. **ผู้ใช้เพิ่มเอง** — แตะบนแผนที่หรือใช้ตำแหน่งปัจจุบัน กรอกชื่อ ชั้น และสิ่งอำนวยความสะดวก (อ่างล้างมือ ปลั๊กไฟ เก้าอี้ โต๊ะเปลี่ยนผ้าอ้อม เครื่องปรับอากาศ) คนเพิ่มนับเป็นการยืนยันครั้งแรก
3. **การยืนยันจากผู้ใช้** — ปุ่ม “ยังมีอยู่ / ปิดแล้ว” ทำให้ข้อมูลสดอยู่เสมอ

ตอนนี้จุดที่เพิ่มและการยืนยันเก็บใน localStorage (คีย์ `momstage:places:v1`) จึงเห็นเฉพาะในเครื่องตัวเอง ข้อมูลนี้ควรแชร์กันทุกคน — ย้ายไป Firestore ได้โดยเขียน repository ใหม่ที่มี `list / add / vote / myVotes` แล้วแก้บรรทัด `export const placeRepository` ท้ายไฟล์ `places.ts` บรรทัดเดียว

### 13. ตั้งชื่อลูกตามวันเกิด (ทักษา) — `src/lib/taksa.ts`

- วันเกิด: ใช้วันเกิด (หรือวันกำหนดคลอดถ้ายังตั้งครรภ์) → `getDay` ของ date-fns · วันทางโหราศาสตร์เปลี่ยนตอน 06:00 (เกิดก่อน 06:00 = วันก่อนหน้า) · วันพุธ 18:00 ถึงก่อน 06:00 ของเช้าวันพฤหัส = **พุธกลางคืน (ราหู)** แอปจึงถามเวลาเกิด (เก็บใน `birthTime` ของลูก)
- อักษร 8 วรรคประจำดาว: อาทิตย์ = สระทั้งหมด (รวม อ) · จันทร์ = ก–ง · อังคาร = จ–ญ · พุธ = ฎ–ณ · เสาร์ = ด–น · พฤหัสบดี = บ–ม · ราหู = ย ร ล ว · ศุกร์ = ศ ษ ส ห ฬ ฮ
- เริ่มที่ดาวประจำวันเกิดเป็น “บริวาร” แล้วนับตามวงทักษา อาทิตย์ → จันทร์ → อังคาร → พุธ → เสาร์ → พฤหัสบดี → ราหู → ศุกร์ ได้ บริวาร อายุ เดช ศรี มูละ อุตสาหะ มนตรี **กาลกิณี** (ลำดับที่ 8)
  - ผลที่ได้: อาทิตย์ → ศ ษ ส ห ฬ ฮ · จันทร์ → สระ · อังคาร → ก–ง · พุธกลางวัน → จ–ญ · พุธกลางคืน → บ–ม · พฤหัสบดี → ด–น · ศุกร์ → ย ร ล ว · เสาร์ → ฎ–ณ
- `analyzeName()` แยกชื่อทีละตัวอักษร บอกว่าอยู่หมู่ไหน (นับตัวการันต์ด้วย ไม่นับวรรณยุกต์) → `filterNames()` เอาเฉพาะชื่อที่ไม่มีอักษรกาลกิณี และเรียงชื่อที่มีอักษรเดช/ศรีขึ้นก่อน
- ชื่อที่กดหัวใจเก็บใน `favoriteNames` ของลูกแต่ละคน
- แหล่งอ้างอิง: ตำราทักษาปกรณ์ตามที่ใช้ในโหราศาสตร์ไทยทั่วไป · ความหมายชื่อสรุปจากรากศัพท์บาลี–สันสกฤตตามพจนานุกรมฉบับราชบัณฑิตยสถาน — ทักษาเป็นความเชื่อ ไม่ใช่หลักวิทยาศาสตร์
