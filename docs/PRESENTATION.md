# MomStage — เอกสารประกอบการนำเสนอ

> “ลูกฉันอายุเท่านี้ ต้องทำอะไร” — กรอกวันที่วันเดียว แอปบอกทุกอย่างที่ต้องทำตอนนี้
> ตั้งแต่ตั้งครรภ์จนลูกอายุ 3 ขวบ

ภาพหน้าจอทุกหน้า (390×844 ข้อมูลตัวอย่าง) อยู่ที่ [`docs/screenshots/`](screenshots/)

## 1. ปัญหาที่แก้

คุณแม่มือใหม่ต้องจำข้อมูลจากหลายแหล่งพร้อมกัน

- **สมุดสีชมพู** มีตารางวัคซีนและพัฒนาการ แต่ต้องนับเองว่าตอนนี้ลูกอายุเท่าไร ถึงคิวอะไร
- **ใบนัดฝากครรภ์** แยกเป็นกระดาษทีละใบ ไม่รู้ว่าสัปดาห์ไหนต้องตรวจอะไรล่วงหน้า
- **กราฟน้ำหนัก/ส่วนสูง** อ่านยากถ้าไม่ได้อยู่ต่อหน้าเจ้าหน้าที่
- **เวลาลูกป่วยกลางดึก** ไม่รู้ว่าต้องไปโรงพยาบาลทันทีหรือรอได้ และไม่แน่ใจขนาดยาลดไข้
- ข้อมูลในอินเทอร์เน็ตมีมาก แต่ **ไม่ได้กรองตามอายุลูกของเรา**

MomStage รวมทุกอย่างไว้ในที่เดียว และ **คัดมาเฉพาะสิ่งที่ตรงกับอายุลูกวันนี้**
ใช้ได้ด้วยมือเดียวบนมือถือ (ปุ่มสูงอย่างน้อย 44px) ไม่ต้องสมัครสมาชิก และไม่ต้องใช้อินเทอร์เน็ตหลังเปิดครั้งแรก
ติดตั้งลงหน้าจอโฮมได้เหมือนแอป (PWA)

## 2. แอปรู้ได้อย่างไรว่าต้องแสดงอะไร

หัวใจของแอปคือแนวคิดเดียว: **วันที่ 1 วัน → อายุ → เทียบตารางทางการ**

```
 ┌────────────────────────┐
 │ ผู้ใช้กรอกวันที่ 1 ครั้ง     │   วันกำหนดคลอด (ตั้งครรภ์) หรือ วันเกิด (คลอดแล้ว)
 └───────────┬────────────┘
             ▼
 ┌────────────────────────┐
 │ คำนวณอายุ ณ วันนี้        │   src/lib/age.ts
 │  • อายุครรภ์ = 280 − (กำหนดคลอด − วันนี้) วัน → สัปดาห์ + วัน
 │  • อายุลูก   = เดือนเต็ม + วัน (date-fns จัดการเดือน 28–31 วัน/ปีอธิกสุรทิน)
 └───────────┬────────────┘
             ▼
 ┌────────────────────────────────────────────────────────┐
 │ เทียบกับตารางทางการที่เก็บเป็นข้อมูลใน src/data/                   │
 │  วัคซีน EPI · นัดฝากครรภ์ 8 ครั้ง · DSPM · WHO LMS · checklist     │
 └───────────┬────────────────────────────────────────────┘
             ▼
 ┌────────────────────────┐
 │ หน้าหลัก (dashboard)      │   ข้อมูลลูก · วงแหวนวัคซีน · น้ำหนัก + กราฟ · % ของที่ต้องเตรียม · พัฒนาการ 5 ด้าน · community
 └────────────────────────┘
```

จุดสำคัญ

1. **ไม่เก็บอายุ เก็บแค่วันที่** อายุคำนวณใหม่ทุกครั้งที่เปิดแอป จึงไม่มีวันล้าสมัย
2. **ตรรกะแยกจากหน้าจอ** ทุกสูตรอยู่ใน `src/lib/*` เป็นฟังก์ชันที่รับ `(ข้อมูล, today)` แล้วคืนผล หน้าจอแค่แสดงผล ทดสอบได้ด้วย unit test โดยไม่ต้องเปิดเบราว์เซอร์
3. **ตารางทางการเป็นข้อมูล ไม่ใช่โค้ด** ถ้ากระทรวงฯ ปรับตาราง แก้แค่ไฟล์ใน `src/data/`
4. **ตรวจวันที่ก่อนบันทึก** วันเกิดในอนาคตถูกปฏิเสธ · กำหนดคลอดผ่านไปแล้วแอปถามว่า “คลอดแล้วหรือยัง?” · ลูกอายุเกิน 3 ขวบแอปแจ้งว่าเกินช่วงที่รองรับ (ไม่พัง)

ตัวอย่าง: กำหนดคลอด 1 มี.ค. 2570 วันนี้ 7 พ.ย. 2569 → เหลือ 114 วัน → 280 − 114 = 166 วัน = **23 สัปดาห์ 5 วัน (ไตรมาส 2)**
→ แอปดึงนัดฝากครรภ์ช่วงสัปดาห์ 21–26, ตรวจเบาหวานขณะตั้งครรภ์ 24–28, วัคซีนไอกรน 20–32 มาแสดง

## 5. สิ่งที่จะพัฒนาต่อ

1. **แชร์ข้อมูลข้ามเครื่องด้วย Firebase**
   - ตอนนี้ข้อมูลอยู่ใน localStorage ของเครื่องเดียว พ่อกับแม่จึงเห็นข้อมูลคนละชุด
   - ใช้ Firebase Authentication (เข้าสู่ระบบด้วย Google/LINE) + Cloud Firestore เก็บโปรไฟล์ลูก แล้วเชิญคู่ชีวิตหรือปู่ย่าตายายเข้ามาดูหรือแก้ไขร่วมกัน
   - โค้ดเตรียมไว้แล้ว: ชุมชน (`src/lib/posts.ts`) และแผนที่ (`src/lib/places.ts`) เขียนเป็น repository ที่คืน Promise ทุก method เปลี่ยนเป็น Firestore ได้โดยเขียน repository ใหม่แล้วแก้บรรทัดเดียว โพสต์และจุดห้องให้นมจะได้เห็นร่วมกันทุกคน
2. **แจ้งเตือนวัคซีนผ่าน LINE**
   - ใช้ LINE Messaging API (Official Account) ส่งข้อความเตือนก่อนวันนัด 7 วันและ 1 วัน
   - ต้องมี backend เล็ก ๆ (เช่น Cloud Functions ตั้งเวลาทุกเช้า) อ่านตารางจาก `getVaccineSchedule()` ตัวเดิม แล้วส่งข้อความหาผู้ที่เชื่อมบัญชี
   - ตอนนี้มีปุ่ม “ส่งออกสรุปวัคซีน” (`buildVaccineSummaryText()`) ที่คัดลอกไปวางใน LINE เองได้แล้ว
3. ต่อยอดอื่น ๆ: แจ้งเตือนผ่าน Web Push ของ PWA, ใช้งานออฟไลน์เต็มรูปแบบด้วย Service Worker, ขยายช่วงอายุถึง 6 ขวบ, ส่งออกรายงานพัฒนาการเป็น PDF ให้แพทย์ดู
